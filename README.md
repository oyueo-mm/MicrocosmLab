# MicrocosmLab

**실제 현미경 관찰 영상으로 미시 세계를 발견하는 한국어 영상 아카이브.**

포식·섭식·면역·감염·세포 활동 등 흥미로운 생물학적 현상을 영상으로 탐색할 수 있어요.

**[사이트 바로가기](https://oyueo-mm.github.io/MicrocosmLab/)** · [짧게 보기](https://oyueo-mm.github.io/MicrocosmLab/#/shorts) · [영상 도감](https://oyueo-mm.github.io/MicrocosmLab/#/videos)

## 주요 기능

- **짧게 보기** — YouTube Shorts처럼 스와이프·휠·키보드로 전환하며 원본 영상을 최대 45초씩 빠르게 감상
- **영상 도감** — 썸네일·한국어 제목 중심 탐색, 생물종·행동 검색/필터, 직접 페이지 이동
- **관련 영상** — 시리즈 그룹, 상세 영상·출처·라이선스, 선호에 따른 콘텐츠 추천
- **생물 도감** — 실제 관찰 대상의 한국어명·학명과 관련 자료
- **영상 출처** — Wikimedia Commons와 제공자가 허용한 YouTube/JoVE 공식 임베드 사용. 영상 파일은 직접 호스팅하지 않음

## 실행

```bash
npm install
npm run dev
npm run build
```

React · TypeScript · Vite · GitHub Pages.
