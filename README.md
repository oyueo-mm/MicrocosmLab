# MicrocosmLab

미시 세계에서 일어나는 실제 행동과 상호작용을 현미경 영상으로 탐색하는 한국어 아카이브. 기존 Wikimedia Commons 영상·외부 공식 재생 영상에 더해 새로운 포식·번식·면역·세포 활동 자료를 지속적으로 확장합니다.

**사이트:** https://oyueo-mm.github.io/MicrocosmLab/

## 콘텐츠

- `data/discovery-videos.json` 및 `data/discovery-extra.json`: 원본 페이지와 설명을 대조한 새 YouTube 자료 총 54개와 행동 태그·흥미도·영상 유형. 유튜브 원본 파일은 내려받지 않습니다.
- `src/recommendations.ts`: 생물종·행동 태그·분류와 이용자 선호에 따른 경량 콘텐츠 기반 추천.
- `src/usePreferences.ts`: 시청 페이지 방문 기록·좋아요·관심 없음 정보를 브라우저에만 보관.
- `data/featured-videos.json`: 원본 출처가 확인된 대표 포식·섭식 영상 4편. 기존 연구 촬영본과 구분해 보존합니다.
- `data/external-videos.json`: 앞서 등록된 사냥·기생 원본 영상 7개. 새 자료 54개와 함께 공식 임베드로 재생합니다. 외부 영상 파일은 복제하거나 직접 스트리밍하지 않습니다.
- `src/grouping.ts`: 동일 연구의 번호별 촬영본을 도감에서 묶어 한 카드로 표시합니다. 서로 다른 파일은 삭제하지 않고 각각 선택해 재생합니다.
- `data/videos.json`: 사이트에 공개되는 승인된 현미경 영상. 영상 이름, 행동, 대상, 설명, 저작자, 라이선스를 포함합니다.
- `data/organisms.json`: 생물·세포 등 등장 대상과 한국어 위키백과 제목. 상세 이미지가 있을 때 위키백과 대표 이미지 또는 해당 대상만 촬영한 영상 썸네일을 사용합니다.
- `data/candidates.json`: 승인 전 후보. 이 목록은 사이트에 자동 게시되지 않습니다.
- `scripts/validate-content.mjs`: 내부 참조와 중복, 필수 저작권 정보 검증.
- `scripts/audit-commons.mjs`: Wikimedia Commons 원본의 파일 존재 여부 및 공개 라이선스 정보 점검. 결과는 GitHub Actions 아티팩트로 제공합니다.
- `scripts/discover-commons.mjs`: 기존 수작업 검수용 후보 수집기입니다.\n- `scripts/bulk-import.mjs`: Commons 메타데이터와 출처 카테고리를 이용해 수집 범위 전체에서 관련 영상 후보를 일괄 등록합니다. 해당 자동 수집 항목에는 **학명·관찰 행동에 대한 추가 육안 검수 필요** 상태가 표시되며, 원본 파일 존재 및 라이선스 검사만으로 과학적 검증을 완료한 것으로 보지 않습니다.\n- `.github/workflows/bulk-import.yml`: 스크립트 변경 시 대량 수집·중복 검사·라이선스 검증을 거쳐 데이터를 커밋합니다.

## 개발

```bash
npm install
npm run validate:content
npm run dev
npm run build
```

## 영상 등록 절차\n\n**기존 자동 수집 자료를 포함한 Commons 영상 1,504개 중 1,313개는 자동 수집된 자료**이며, 원본 메타데이터 검증과 장면·종에 대한 개별 검수 상태를 구분해 관리합니다. 최신 수집의 검색 범위는 면역세포·바이러스 감염·섬모충·윤충·아메바·점액세균 등입니다.

1. `npm run discover:commons` 실행 후 `artifacts/commons-candidates.json`에서 후보를 찾습니다.
2. 원본 파일 페이지에서 **실제 관찰 영상인지**, 등장 생물 및 행동 설명이 일치하는지, 저작자와 라이선스가 올바른지 검토합니다.
3. 검토한 파일만 `data/videos.json`에 추가하고, 신규 등장 대상이 필요하면 `data/organisms.json`에 등록합니다.
4. `npm run validate:content`와 `npm run audit:commons`로 검증합니다.
5. GitHub `main`에 반영하면 Actions가 GitHub Pages에 배포합니다.

## 사용자 인터페이스

- 영상 카드: 동일한 연구에서 번호가 붙은 촬영본은 한 카드로 묶고, 상세 화면에서 1편·2편 등으로 전환할 수 있습니다. 파일은 삭제하지 않습니다. 대표 영상 3개도 하나의 카드로 묶습니다.
- 외부 영상: 일반 영상과 동일한 카드와 **동일한 상세 페이지**를 사용합니다. 영상·제목·행동 분류·설명·등장 대상·출처 패널을 같은 위치에 표시하며, 영상은 페이지 안에서 YouTube/JoVE 공식 임베드 플레이어로 재생합니다. 별도의 팝업이나 새 탭으로 자동 이동하지 않습니다. 원본 제공처가 임베드를 차단하면 해당 영상은 재생되지 않을 수 있습니다.
- 영상 카드: 썸네일과 제목. 행동 분류는 상세 화면에서 확인합니다. 한 페이지에 12개 영상만 표시하며 페이지 번호를 눌러 이동합니다. 미디어 정보는 현재 및 다음 페이지의 영상만 요청합니다.
- 등장 대상: 작은 대표 이미지, 한국어 이름 및 학명. 이름 클릭 시 한국어 위키백과 문서로 이동하며 문서가 없다면 나무위키 검색으로 연결합니다.
- 추천 V1: 홈의 **취향에 맞는 영상 · 강렬한 포식과 방어 · 새로운 발견**, 상세 화면의 유사 콘텐츠를 추천합니다. 생물종/분류/명시 태그와 페이지 열람, 좋아요·관심 없음이 반영되며 데이터는 브라우저 `localStorage`에만 보관합니다. 아직 로그인·DB·협업 필터링은 없습니다.

## 저작권 및 라이선스

저장소의 자체 소스코드는 [MIT](LICENSE) 라이선스로 배포합니다. **영상과 대표 이미지는 각 원저작자의 라이선스를 따릅니다.** 외부 영상 원본은 이 저장소에 포함하지 않으며 상세 페이지에서 출처, 제작자 및 라이선스를 공개합니다.

자동 검증은 파일 존재 및 기계 판독 가능한 메타데이터를 확인하는 보조 절차일 뿐, 학명·행동·영상 장면을 과학적으로 검증하는 과정까지 대체하지 않습니다.

- 기존 380개에서 1,500개로 확장했습니다. 새로 확보한 1,120개에는 원본 설명과 재사용 라이선스가 확인된 포식·섭식 영상 7개가 포함됩니다.
- Commons 카테고리별 중복 파일을 제외하고, 원본 파일 존재 및 라이선스 정보에 대한 자동 검증을 통과했습니다.
- **중요:** 자동 수집된 대다수 항목의 생물학적 동정, 관찰 행동, 시각적 흥미도는 아직 개별 검수되지 않았습니다. 자동 분류·설명은 원본 카테고리에 기반한 잠정값입니다.
- 인체 면역세포·감염·섬모충·윤충·아메바·선충·세포 분열 관련 영상들을 수집했으며, 도감은 페이지당 12개 영상만 표시합니다.

## 포식 영상 및 시리즈 통합 (2026-11-18)

- Commons 라이선스가 확인된 Bdellovibrio의 대장균 침입 타임랩스 3편을 새로 추가했습니다 (CC BY 2.5). 3편은 하나의 카드에서 선택할 수 있습니다.
- 외부 영상 61개도 일반 영상과 동일한 썸네일·제목 카드로 노출하고, 클릭 시 내부 상세 페이지의 플레이어에서 공식 임베드 방식으로 재생합니다. 실제 파일 자체는 재배포하지 않습니다.
- 기존 영상에서 같은 연구 파일명, 행동 분류 및 등장 대상이 일치하는 촬영본은 자동으로 묶습니다. 영상 수는 보존하면서 카드 중복만 줄입니다. 같은 연구의 실험 조건별 영상이 포함될 수 있으므로 별도 클립으로 전환할 수 있습니다.
- 기존 자동 분류 결과는 개별 육안 검수 전까지 확정적인 생물학적 분류로 간주하지 않습니다.

## 콘텐츠 확장 + 추천 V1 (2026-11-18)

- YouTube 원본 설명·전문 연구기관의 공개 해설 등과 대조한 신규 후보 54개를 검수 대상 메타데이터로 등록했습니다. 원본 파일은 저장하지 않고 공식 YouTube 임베드를 사용합니다. 영상별 재생 허용·자세한 장면의 개별 육안 검수는 별도 과정입니다.
- Commons에서 기존 영상과 중복되지 않는 모기 유충 섭식 영상 1개를 추가했습니다 (CC BY-SA 4.0). 기존 1,500편과 신규 Commons 4편을 합쳐 총 1,504편입니다.
- 신규 자료에는 서술형 행동 태그, 등장 대상, 콘텐츠 유형(현미경 원본·해설 영상), 편집자의 1~5 흥미도 평가 및 출처 검증 상태를 기록했습니다. 기존 자동 수집 영상은 단정적인 고품질 자료로 간주하지 않고 범주·제목을 활용한 약한 추천 신호로만 취급합니다.
- 추천 시스템은 처음 방문한 사용자를 위한 검수 영상 우선 배치부터 최근 페이지 열람, 좋아요, 관심 없음 반영까지 지원합니다. 단순 페이지 방문은 재생 완료 기록이 아닙니다.
- 영상 ID·원본 링크·파일 이름의 중복을 정적 검증하며, GitHub Pages 무료 정적 호스팅을 유지합니다. 협업 필터링, 별도의 수집 서버나 추적용 DB는 사용하지 않습니다.

## 영상 탐색·추천 V2 및 후보 발굴

- **탐색**: 행동 필터, 흥미도·이름 정렬, 현재 필터를 존중하는 랜덤 발견. 랜덤 선택 시 관심 없음 영상과 이미 본 영상을 우선 피하고, 메타데이터 신뢰도가 높은 영상을 우선합니다.
- **추천 V2**: 기존 상세 페이지 방문·좋아요·관심 없음에 더해 Commons 원본 플레이어의 실제 재생 시작 및 탐색 이동 시간을 제외한 누적 재생 시간 70% 이상을 로컬 선호 신호로 기록합니다. 외부 YouTube/JoVE 임베드는 시청 완료를 추측하지 않습니다. 저장은 기존 브라우저 로컬 저장소에만 수행합니다.
- **검수 상태**: 대표 영상, 원본 메타데이터 확인, 개별 장면 검수 필요 상태를 분리합니다. 자동 메타데이터 검증이나 YouTube API 검색 결과만으로 생물학적 관찰을 확정하지 않습니다. `node scripts/quality-report.mjs`는 `artifacts/content-quality-report.json`을 생성합니다.
- **자동 후보 발굴**: `.github/workflows/discover-content.yml`을 수동 실행하거나 매주 월요일 UTC 02:00에 실행하면 Commons·YouTube 후보와 콘텐츠 품질 보고서를 Actions 아티팩트로 제공합니다. GitHub에 영상을 직접 저장하지 않고 **후보를 자동 게시하지 않습니다**.
- **YouTube 검색 설정**: 저장소 Actions secret `YOUTUBE_API_KEY`에 YouTube Data API v3 키가 있으면 새로운 공개·임베드 허용 후보를 수집합니다. 키가 없으면 YouTube 검색만 건너뛰고 보고서와 Commons 후보 수집은 계속합니다. API가 공개·임베드 허용을 표시해도 실제 장면·저작권·재생 여부는 별도 검토가 필요합니다.
- **테스트**: `node scripts/test-recommendations.mjs`, `node scripts/test-explorer.mjs`, `npm run build`. 기존 이용자 선호는 자동으로 새 필드가 추가되며 보존됩니다.

## 홈 추천 확장 및 분리된 품질 검사 (2026-11-19)

- 홈의 세 추천 영역은 각각 **4열 × 2줄(8개)**부터 보여줍니다. 모바일에서는 2열로 표시하며, `더 보기`로 8개씩 아래에 추가하고 `접기`로 해당 영역만 초기화합니다. 수평 스크롤·좌우 이동 버튼은 제거했습니다.
- 추천 V2는 영역당 최대 40개까지 후보를 준비하지만, 처음에는 8개씩만 렌더링합니다. Commons 썸네일 API도 **화면에 노출된 추천 카드**만 요청합니다. 영상 도감 필터와 상세 플레이어는 유지합니다.
- 콘텐츠 품질은 `재생 확인`, `생물종·행동 정확성`, `기술적 영상 품질`, `흥미도`, `원본 중복·시리즈`로 **독립 기록**합니다. `scripts/quality-report.mjs`가 `artifacts/content-quality-report.json`에 영상별 항목과 점검 목록을 생성합니다.
- **우수/보통/검수 필요/제외 대상 등 하나의 등급은 만들지 않습니다.** 오프라인 메타데이터만으로 영상 재생 성공, 해상도, 선명도를 확인할 수 없으므로 해당 값은 미측정으로 명시합니다. 관심도 점수는 원본 데이터에 직접 존재할 때만 사용하며 결측치를 임의로 채우지 않습니다.
- 일반 영상 상세 화면에서 내부 검수 단계를 표시하지 않으며, 출처·저작권·관찰 주석은 기존대로 보존합니다.
- 검증: `node scripts/test-recommendations.mjs`, `node scripts/test-quality-report.mjs`, `npm run build`. 비디오 원본은 다운로드하거나 별도 보관하지 않습니다.

## 영상 도감·상세 UI 개선 (2026-11-19)

- 영상 도감: 주요 분류와 추가 분류, 추천순/흥미도순/이름순, 선택형 행동 필터를 **하나의 탐색 영역**으로 정리했습니다. 조건 초기화와 현재 검색 결과 카드 수를 표시하며, 기존 검색·랜덤 발견 기능을 유지합니다.

## 대량 발굴 → 자동 검사 → 일괄 등록 파이프라인

- **Commons 자동 파이프라인**: `node scripts/batch-commons.mjs --max=120 --scan=1800 --pages=2`는 31개 이상의 현미경·생물 주제 카테고리를 조사하고 파일명, 영상 MIME, 저작자, CC BY/CC BY-SA 라이선스 및 이미 등록한 원본 중복 여부를 확인합니다. `artifacts/batch-discovery-report.json`과 `artifacts/batch-ready-commons.json`을 생성하며 기본 동작은 **미게시 미리보기**입니다.

- **자동화**: `.github/workflows/batch-discovery.yml`은 매주 화요일 자동 실행 또는 GitHub Actions 수동 실행으로 원본 후보를 찾고, 확인된 신규 영상만 담은 **검토 가능한 PR**을 생성합니다. 승인·병합하지 않은 데이터는 공개되지 않습니다. GitHub 저장소 설정에서 Actions의 PR 생성 권한을 허용해야 PR 자동 생성이 가능합니다. 공개 저장소라도 실제 생물종·행동의 장면 검수는 별도로 필요합니다.
- **즉시 미리보기**: `.github/workflows/batch-discovery-preview.yml`은 PR에서 검사를 실행하고 수집 후보를 GitHub Actions 아티팩트로 저장합니다. 콘텐츠를 직접 게시하지 않습니다. 전체 등록 검증과 파이프라인 회귀 테스트도 빌드·배포 필수 과정입니다.
- **YouTube 자동 탐색**: `scripts/discover-external.mjs`는 최대 26개 주제로 350개까지 API 메타데이터 후보를 확인하고 기존 영상 ID를 제거합니다. `YOUTUBE_API_KEY` 시크릿이 필요하며, 키가 없으면 YouTube 탐색만 생략합니다. 공개·임베드 허용 여부는 자동 확인 가능해도 실제 재생·생물종·행동의 정확성은 판정할 수 없으므로 YouTube 후보는 자동 게시하지 않고 `artifacts/external-video-candidates.json`으로 분리합니다.
- **과학적 검수 범위**: 자동 등록된 Commons 자료의 생물 분류는 Commons 카테고리를 이용한 보수적인 메타데이터 추정이며, 그 사실을 영상 설명과 관찰 정보에 명시합니다. 자동 등록은 개별 장면의 육안 검수 완료를 의미하지 않습니다.

- **제목·설명 정리:** 기존 자동 수집 동영상 2,730건의 제목을 연구 파일명·주제와 촬영본 번호를 포함한 구별 가능한 제목으로 정규화했습니다. 생성 영상 제목의 정확한 중복은 0건이며, '선충의 현미경 관찰'이라는 같은 제목이 계속 반복되지 않습니다. 불확실한 과학적 동작은 단정하지 않고 원본 연구 주제 기반 설명과 '개별 검수 필요'를 표시합니다. 연구 제목이 영어인 경우에는 임의로 번역해 사실을 바꾸지 않고 원문을 보존합니다.
- **오분류 방지:** `Repeats` 안의 `eats`를 먹이 섭취로 인식하던 정규식을 수정했고, 오분류된 선충 운동 연구 4개를 고쳤습니다. 원본 파일명에서 명확한 근거가 없는 포식·번식·방어 등의 행동 주장은 보수적인 분류로 되돌렸습니다.
- **연구 묶음 개선:** 같은 논문의 연속 촬영본을 하나의 카드로 묶어 개별 영상은 계속 선택할 수 있습니다. 12편보다 많은 연구는 간결한 드롭다운으로 선택합니다. `src/grouping.ts`는 연구별 묶음을 캐시하며, 데이터가 증가해도 카드마다 모든 원본을 다시 반복 탐색하지 않습니다. 원본 Commons 2,921개는 시리즈를 적용하면 **1,120개 대표 카드**로 표시됩니다(외부 76개 추가 시 총 1,196개 탐색 카드).
- **추천·검색 신뢰도:** V3의 입력에서 아직 장면 검수 전인 영상의 연구 설명을 검증된 '포식·감염' 동작으로 간주하지 않으며, 자동 수집 메타데이터 자료의 신뢰도를 적절히 낮춰 반영합니다. 기존 좋아요·관심 없음·시청 기록은 유지합니다.
- **메타데이터 조회·캐싱:** 생물 도감에서 수천 파일을 동시 조회하던 동작을 현재 표시된 생물의 대표 영상만 요청하도록 줄였고, Commons 포스터·WebM 주소를 페이지 이동 간 캐시하며 실패 후 재시도 간격을 둡니다. 빌드는 원본 영상 데이터와 라이브러리를 캐시 가능한 별도 JS 청크로 분리합니다. **정적 카탈로그 전체를 완전히 지연 로딩하는 방식은 아직 아니므로 초기 네트워크 총량이 0이 되는 것은 아닙니다.**
- **재생·썸네일 표본 검사:** `scripts/audit-playback.mjs`는 Commons 파생 비디오·포스터 및 일부 HTTP HEAD 응답을 검토합니다. `.github/workflows/playback-audit.yml`로 매주 금요일과 수동 실행, PR 수정 시 보고서 아티팩트를 생성합니다. 첫 실행의 Commons 표본 72개는 WebM 파생 파일이 확인됐고 메타데이터 API 오류는 0건이었습니다. 이는 브라우저별 재생·YouTube iframe·실제 장면 검수를 보장하지 않습니다.
- **수집 파이프라인 재발 방지:** `scripts/catalog-cleanup.mjs` 정규화를 자동 수집·수동 일괄 백필에도 적용합니다. 콘텐츠 검사와 PR/Pages 검증에서 반복 생성 제목·'Repeats' 오탐·검수 주의문 누락을 차단합니다. 1,500개 목표로 멈추는 구형 백필 워크플로는 수동 실행 전용으로 바꾸고, 매주 수집 PR을 만드는 신규 대량 수집 파이프라인은 유지합니다.

**검사 명령:** `node scripts/test-catalog-cleanup.mjs`, `node scripts/test-grouping.mjs`, `node scripts/validate-content.mjs`, `node scripts/test-recommendation-v3.mjs`, `npm run build`. 이번 통합 수정은 PR #9에서 검증 후 `main`에 병합합니다.

## 페이지 직접 이동·한국어 연구 제목·45초 빠른 관찰 (2026-11-20)

- **영상 도감 페이지 이동:** 하단 페이지네이션의 입력칸에 원하는 페이지 번호를 입력하고 Enter 또는 **이동**을 누르면 해당 페이지로 바로 이동합니다. 예: 88페이지. 정수가 아니거나 범위를 벗어나면 이동하지 않으며 기존 검색/분류 필터 상태는 유지합니다.
- **한국어 제목:** 자동 수집한 연구 영상의 긴 영어 제목 대신 생물명·관찰 현상·단백질/유전자 기호를 중심으로 정리한 짧은 한국어 제목을 카드와 상세 화면에 표시합니다. 사람이 검수한 자연어 문장 전체 번역이 아니라, **한국어 연구 주제 요약**이며 장면이나 논문의 결론을 임의로 확정하지 않습니다. 신뢰할 수 있는 연구 용어/현상은 규칙과 선별 교정으로 처리하고, 한국어 제목의 중복은 연구별 기록 식별자로 구분합니다. 원제목은 상세 화면의 **원문 연구 제목**에서 확인할 수 있습니다. 검색·이름순 정렬도 한국어 제목을 지원합니다.
- **짧게 보기** (`#/shorts`): 홈·영상 도감·좌측 메뉴에서 진입하여 Wikimedia Commons 영상을 **한 편당 최대 45초씩 빠르게 미리보기**로 재생합니다. 실제 길이가 45초인 원본만 모은 목록이 아니며, 원본 길이가 길어도 45초 이후 다음 영상으로 넘어갑니다. 자동 재생은 음소거 기본, ↑/↓ 또는 PageUp/PageDown으로 이전·다음, Space로 일시정지/재생, 모바일에서 위아래 스와이프, 속도 1×/1.5×/2×, 음량·좋아요·관심 없음 및 **전체 영상 보기**를 지원합니다. 원본 영상 저장·재인코딩은 하지 않습니다.
- **검증:** 새 `scripts/test-korean-and-shorts.mjs` 및 기존 카탈로그·추천·빌드 테스트를 PR와 GitHub Pages의 필수 검증 과정에 연결했습니다. 이번 검사에서 자동 생성 자료 2,730건의 제목이 한국어 우선으로 표시되며, 실제로 노출되는 Commons 연구 카드 1,120개의 한국어 표제가 서로 동일하지 않도록 확인했습니다.
- **한계:** 과학 용어가 많은 복잡한 연구 제목을 모두 완전하게 번역하는 서비스는 아니고, 자동 요약이 정확한 연구 기전을 대체하지 않습니다. 별도 품질 검수와 전문 분야별 용어 사전 확장이 앞으로의 개선 영역입니다. 브라우저의 자동 재생 정책이나 Commons 서버 문제로 실제 재생이 실패할 수 있으므로 원본 링크와 건너뛰기를 제공하고 있습니다.
