# MicrocosmLab

한국어 현미경 행동 영상 아카이브. 포식, 이동, 먹이 섭취, 접합, 면역 반응 등 미시 세계의 실제 관찰 장면을 찾아볼 수 있습니다.

> 초기 버전 개발 중 · React / TypeScript / Vite

## 운영 원칙

- 관찰 사실은 원본 영상의 설명과 연구 자료를 우선합니다.
- 등장 대상의 상세 정보는 한국어 위키백과를 우선 연결하고, 문서가 없을 때 나무위키 검색으로 연결합니다.
- 모든 영상은 원본 제작자·출처·라이선스를 명시합니다. 외부 영상은 별도로 내려받아 저장하지 않습니다.
- 설명만으로 확인할 수 없는 생물 종 또는 행동은 추정하지 않습니다.

## 개발

`npm install` 후 `npm run dev`로 로컬 미리보기를 열고 `npm run build`로 빌드합니다.

## 배포

GitHub 저장소를 Cloudflare Pages에 연결하고, 빌드 명령어 `npm run build`, 출력 디렉터리 `dist`를 설정합니다. SPA 내비게이션은 해시 라우팅을 이용합니다.

## 라이선스

사이트 자체 코드는 MIT 라이선스입니다. 외부 미디어는 각각의 원본 라이선스를 따릅니다. 자세한 출처는 영상 상세 페이지 및 `src/data.ts`를 참조하세요.
