## 현재 중요한 판단

- **추천 운영 기준선은 V3**. V4 TF-IDF·BM25·콘텐츠 KNN·하이브리드·MMR은 연구 후보이고, 다국어 Sentence Embedding 실제 384차원 실험을 완료했으나 성능만으로 교체하지 않았습니다.
- 과거 메타데이터 기반 관련성 평가에서 **정답 생물종/카테고리와 KNN 입력 특징의 중복에 따른 평가 편향**이 발견됨. 다음 연구는 사람의 독립적인 영상 관련성·선호 판단과 별도 홀드아웃 평가 설계가 우선입니다.
- 시청 시간·빠른 넘김 등 행동 신호는 현재 로컬 브라우저에만 저장합니다. 서버 간 사용자 통합과 협업 필터링은 아직 운영하지 않습니다.
- 자동 수집 콘텐츠의 과학적 검수 여부, 영상 재생 성공률과 실제 장면 재미는 별도로 검증해야 합니다.

**공유 규칙:** 문서와 최신 소스가 다르면 최신 검증된 코드·실험 결과를 기준으로 고치고, 관련 문서를 같은 PR에서 갱신합니다.
