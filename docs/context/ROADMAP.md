## 다음 우선순위 (제안, 아직 구현되지 않음)

### P0 — 추천 평가의 독립성 확보

- PR #15에서 **로컬 블라인드 평가 UI 및 여러 모델 후보 Pool 생성과 JSON 내보내기**를 구현. 실제 사람의 판단 수집·독립 평가자 일치도·홀드아웃 평가는 아직 미완료. 근거: [발견형 추천 연구](../recommendation/DISCOVERY-STUDY-2026-11-21.md).

- 기존 `scripts/test-recommendation-lab.mjs`는 **동일 생물종/카테고리 정답 기반 메타데이터 대리 지표**임을 유지·표시하고, 새로운 사람 평가 결과와 혼동하지 않습니다.
- 인간 평가용 기준 영상 30개 내외를 다양한 생물종·행동·품질 수준에 따라 층화 선정합니다. 숫자는 시작 제안으로 조정 가능합니다.
- 각 기준 영상에 대해 V3·TF-IDF·BM25·KNN·Hybrid/MMR·Sentence Embedding·무작위 후보를 모아 **중복 제거·블라인드·무작위 순서로 평가**하는 공정한 후보 Pool을 구성합니다.
- 평가자는 제목만 보지 않고 **실제 영상 장면을 보고** 콘텐츠 관련성(예: 0–3), 다음 시청 의향(또는 A/B 둘 중 선호/둘 다 관심 없음), 흥미도를 개별 평가합니다. 독립 평가자 2명 이상을 확보하고 불일치도 보고합니다.
- **미평가 영상을 자동으로 오답으로 간주하지 않고**, 개발 셋과 독립 최종 홀드아웃 셋을 분리합니다. 후보 Pool의 잔여 편향과 평가자 주관성도 공개합니다.
- 사람 평가용 벤치마크는 아직 **미구현**. 구축 이후 V3와 V4 후보를 재평가한 다음 모델 승격 여부를 논의합니다.

### P1 — 실제 이용자의 개인화 품질 측정

- 로컬 데이터에서 재생·짧은 넘김·시청 비율의 의미를 구분하고, 자동 재생과 사용자의 적극적 선택을 다르게 취급합니다.
- 서비스에서 선택 동의 기반 데이터 수집을 도입하려면 목적·이벤트·가명 키·삭제/철회·로그·보관 기간·스팸/레이트리밋·비용을 검토한 **별도 백엔드 설계와 사용자 승인**을 우선합니다.
- 실사용 로그가 생긴 뒤에만 선택 편향과 노출 확률을 고려한 A/B 및 밴딧 연구, ItemKNN·LightGCN 학습을 계획합니다.

### P2 — 콘텐츠와 UX 품질 향상

- 영상의 개별 장면 정확성·흥미도·재생 성공률을 별도 검수하고, 서로 다른 촬영본의 유사·중복 노출을 관리합니다.
- 기존 유튜브형 UI와 원본 종횡비·라이선스·한글 제목·시리즈 선택 기능을 회귀 없이 유지합니다.
