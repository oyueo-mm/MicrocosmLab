## 현재 운영 시스템

- **서비스:** https://oyueo-mm.github.io/MicrocosmLab/ · GitHub Pages 정적 사이트.
- **기술:** React 19 · TypeScript · Vite 7.
- **콘텐츠:** 2026-11-20 스냅샷 기준 Commons 2,921개 + 외부 76개 = 원본 기록 2,997개, 대표 도감 카드 1,196개(동일 연구 촬영본 그룹 포함).
- **UI:** YouTube형 썸네일 홈·영상 도감·상세 화면·쇼츠, 45초 미리보기, 한국어 제목, 직접 페이지 이동.
- **운영 추천:** `src/recommendationV3.ts`의 V3. 로컬 `localStorage` 개인화(좋아요/시청/숨김/넘김/재생 구간).
- **연구용 추천:** V4 TF-IDF·BM25·콘텐츠 KNN·Hybrid·MMR, 실제 `paraphrase-multilingual-MiniLM-L12-v2` 384차원 임베딩 평가. 연구용 코드는 서비스 기본 추천에 연결하지 않음.
- **협업 추천:** ItemKNN·LinUCB 합성 데이터 기반 프로토타입, 그래프 전파 구현. LightGCN 실학습 및 실사용 데이터 기반 협업 추천 **아직 없음**.
- **이용자 서버 데이터:** **없음.** 개인정보 동의 기반 백엔드 수집은 미구현. 로컬 행동 기록을 무단 업로드하지 않음.

## 추천 오프라인 평가

### 2026-11-21 1차 V4 오프라인 결과 (메타데이터 대리 지표)

- PR #13에서 실행된 GitHub Actions 빌드/테스트에서 대표 카탈로그 **1,196건**, 생물종·카테고리 기반 **42개 합성 관련성 사례**로 결과 산출. 정답은 사용자 선호가 아니라 동일 메타데이터 집합이다.
- NDCG@10 대리 지표: **V3 0.7595**, TF-IDF 0.4063, BM25 0.3694, **콘텐츠 KNN 0.8551**, 하이브리드 0.7091, 하이브리드+MMR 0.6906. KNN이 높은 이유에는 **평가 정답이 생물종·카테고리를 공유하도록 설계된 편향**이 있으므로 실사용자 추천 품질 향상을 주장하지 않는다.
- 재현: `node scripts/test-recommendation-lab.mjs`. 검증 로그: [GitHub Actions #44840548971](https://github.com/oyueo-mm/MicrocosmLab/actions/runs/44840548971). 최종 모델 승격은 실제 사용자 행동 기반 평가 이후 결정.
- **실제 Sentence Embedding 결과**: `paraphrase-multilingual-MiniLM-L12-v2`를 실행해 1,196개 영상의 384차원 벡터를 만들고 동일 기준을 검증했다. 임베딩 단독 nDCG@10 대리 지표 **0.4211**, 임베딩+하이브리드 **0.6615**. 실행 증거 [Actions #44840692750](https://github.com/oyueo-mm/MicrocosmLab/actions/runs/44840692750), 표/한계 [RESULTS-2026-11-21.md](../recommendation/RESULTS-2026-11-21.md). 정확한 생물종 일치를 보상하는 메타데이터 대리 지표이므로 문장 의미 추천의 일반화 품질까지 판단하지 않는다.

**해석:** 생물종·카테고리 일치로 관련성을 정의했기 때문에 이 특징을 직접 쓰는 콘텐츠 KNN에 유리한 평가입니다. 각 수치는 실사용자 만족도나 실제 추천 품질 향상을 입증하지 않습니다. 과학적 장면 검수·재생 성공 여부 역시 이 평가로 입증되지 않습니다.
