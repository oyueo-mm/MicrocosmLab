# 확정된 결정과 변경 시 고려사항

## 기존 핵심 결정

1. 복잡한 이론 설명보다 시각적 흥미와 실제 관찰 장면을 먼저 보여준다. 홈·도감·상세·쇼츠의 유튜브형 UX 일관성을 유지한다.
2. 데이터 양이 많아도 **동일 연구 중복 카드, 의미 없는 단순 연구 자료, 낮은 품질·재생 불가능 영상**을 무작정 상단에 노출하지 않는다.
3. 외부 영상은 가능하면 사이트 내부의 **허용된 공식 임베드**를 제공하고, 불가한 것은 사유/원본 링크로 안내한다. 저장 공간 확보를 위해 동영상 파일을 직접 내려받거나 보관하지 않는다.
4. 등록·추천·검색에서 과학적 검수되지 않은 행동 설명을 확정 사실로 바꾸지 않는다. 저작자·라이선스·원제를 보존한다.
5. 개인화 기록·영상 ID·시리즈 그룹핑·기존 추천 기준선을 함부로 초기화하지 않는다.
6. 명확히 측정되지 않은 성능·실사용자 반응·온라인 개선을 수치로 지어내지 않는다.

## 추천 연구·평가 원칙

- **실제 사람에게 추천하는 품질**과 **생물종·카테고리의 일치도**는 다른 목표입니다. 메타데이터 동일성을 정답으로 삼은 실험에서 KNN이 높게 나오는 현상은 입력 특징과 라벨 정의가 직접 겹치는 평가 편향일 수 있습니다.
- 현재의 V3는 **검증된 배포 기준선**으로 유지합니다. TF-IDF/BM25, Sentence Embedding, 콘텐츠 KNN, MMR 등 실험 후보는 반복 가능한 결과와 평가 목표를 분리한 후 비교합니다.
- 실사용자 관련성·선호도 실험은 **아직 설계 제안**입니다. 같은 생물종이라 무조건 정답 처리하지 말고, 실제 영상을 본 평가자들이 관련성·다음 시청 선호·새로움 등을 독립적으로 평가하도록 합니다.
- 수집·동의한 데이터가 확보되기 전까지 **ItemKNN/LightGCN의 실사용자 효과를 주장하거나 서버 수집을 몰래 활성화하지 않습니다.**
- 오프라인 메타데이터 기반 NDCG와 실제 사용자 선호 NDCG를 문서·그래프에서 혼용하지 않습니다. 모델 선택·튜닝에 이용한 평가셋을 독립 홀드아웃으로 재사용하지 않습니다.

## 결정 변경 기록 방식

중요한 선택을 바꾸면 날짜, **변경 전 → 변경 후**, 근거 실험/이슈/PR, 영향받는 코드와 롤백 방법을 기재합니다. 단순 제안은 [ROADMAP.md](ROADMAP.md)에 기록하고, 확정되기 전 결정으로 표현하지 않습니다.
