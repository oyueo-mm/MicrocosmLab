## 조건
- **실제 사용자 선호 데이터 0건**. 카탈로그 대표 영상 1,196개와 메타데이터만 사용.
- 42개의 평가 시드에서 **같은 생물종 ID + 같은 카테고리**를 공유하는 아이템을 관련성 1로 간주하여 Recall@10 및 nDCG@10의 **대리 지표**를 계산했다. 관련성 정답이 사용자 관찰·선호로부터 얻어진 것이 아니므로 지표에 반드시 **메타데이터 대리 지표**라고 표기한다.
- 모든 실험은 같은 카탈로그와 같은 정답 대리 기준을 사용하고, 구간당 10개를 평가한다. 종/분류 특징을 직접 사용하는 KNN에 평가상 이점이 있다는 점을 반드시 고려한다.
- 추가 임베딩 모델: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, 다국어 문장 임베딩 **384차원 × 1,196개**. GitHub Actions 수동 연구용 아티팩트에서 생성/평가, 사이트 클라이언트·운영 서버에 모델을 설치하지 않았다.

## 결과

| 후보 | Recall@10 대리 지표 | nDCG@10 대리 지표 | 평균 카테고리 다양성@10 | 평균 제작자 다양성@10 |
| --- | ---: | ---: | ---: | ---: |
| V3 (현재 기본값) | 0.7619 | 0.7595 | 4.69 | 8.10 |
| TF-IDF | 0.5000 | 0.4063 | 3.40 | 5.21 |
| BM25 | 0.4524 | 0.3694 | 3.67 | 5.21 |
| **콘텐츠 KNN** | **0.9190** | **0.8551** | 2.93 | 6.36 |
| 하이브리드 | 0.7762 | 0.7091 | 3.26 | 5.24 |
| 하이브리드 + MMR | 0.7286 | 0.6906 | 3.86 | 5.62 |
| 실제 Sentence Embedding | 0.3952 | 0.4211 | 3.00 | 5.40 |
| Embedding + Hybrid | 0.7333 | 0.6615 | 3.14 | 5.05 |

- 모든 후보가 위 테스트에서 **10개 아이템 중 중복 ID 없이 10개를 반환**했다.
- **KNN의 높은 관련성 점수와 낮은 카테고리 다양성은 상충 관계**다. 영상 관찰 서비스에서 이용자가 유사 생물만 반복 시청하고 싶은지, 색다른 관찰 주제를 원하는지는 실사용 피드백이 필요하다.
- MMR은 이번 평가에서 카테고리·제작자 다양성이 기본 하이브리드 대비 높았지만 관련성 대리 지표는 낮아졌다. 사용자 만족도나 다양성 품질 개선으로 단정하지 않는다.
- 임베딩 단독의 낮은 점수는 해당 모델이 나쁘다는 뜻이 아니다. 연구용 텍스트에는 자동 수집·축약 제목 등 불확실한 메타데이터가 있고, 평가 정답 또한 **정확한 생물종/카테고리 동일성**에 맞춰져 있어 의미적 근접성을 과소평가할 수 있다.

## 결론 및 다음 평가

1. **운영 추천 V3는 그대로 보존**한다. 이번 오프라인 대리 지표만으로 V4를 서비스 기본값으로 승격하지 않는다.
2. 다음 관련성 평가에는 사람이 개별 장면을 확인한 **질문-영상 쌍**과 최소 2인 이상의 독립 평가자, 주제별 층화 표본, 의미적 관련성(단순 메타데이터 중복과 구분)을 도입한다.
3. 장면 정확성·흥미도·재생 성공률·저작권 검증은 추천 유사도와 별도의 품질 제약으로 유지한다.
4. 브라우저 로컬의 실제 재생·짧은 넘김·좋아요 등을 개인화에 보수적으로 활용하고, 여러 사용자의 협업 정보는 **동의/삭제/보존/보안 정책이 포함된 별도 백엔드 준비 이후**에만 수집한다.
5. LinUCB/ItemKNN/LightGCN은 현재 실사용자 데이터가 없으므로 성능 순위를 발표하지 않는다. 코드상의 그래프 전파 테스트는 **실제 LightGCN 학습이 아님**.
